# gltf example

Deformed cube with unchanged vertex counts, moved marker, added object, material colour.

```bash
artifactdiff diff examples/gltf/old.glb examples/gltf/new.glb
```

`expected.json` lists the expected status and the (kind, category, path) of every change; `artifactdiff demo --check` verifies it. Generated by `scripts/generate_examples.py` (synthetic data).
