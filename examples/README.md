# Examples

One directory per format with `old.*`, `new.*`, `expected.json` and a README. All files are synthetic,
generated by [`scripts/generate_examples.py`](../scripts/generate_examples.py), and redistributable under
the project license.

```bash
artifactdiff demo                    # run them all
artifactdiff demo --check            # verify results against expected.json
artifactdiff demo --output-dir out   # write HTML/Markdown/JSON reports
```

Also here: [`plugins/artifactdiff-plugin-ini`](plugins/artifactdiff-plugin-ini) (a complete third-party plugin)
and [`workflows/artifactdiff.yml`](workflows/artifactdiff.yml) (a ready-to-copy GitHub workflow).
