# safetensors example

Fine-tuned weights, a renamed tensor, a reshaped head, an added layer, metadata.

```bash
artifactdiff diff examples/safetensors/old.safetensors examples/safetensors/new.safetensors
```

`expected.json` lists the expected status and the (kind, category, path) of every change; `artifactdiff demo --check` verifies it. Generated by `scripts/generate_examples.py` (synthetic data).
